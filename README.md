# Chaikhana Tea House (Midterm Project)

**Topic:** website for a Central Asian tea house.

**Pages:** Home, About, Menu, Gallery, Contact (navbar on every page).

**Features**
- Semantic HTML5 (header, nav, main, section, article, figure, address, footer)
- Table (menu) and form (table reservation)
- CSS: classes/IDs, Flexbox (feature row), Grid (gallery), fixed navbar + absolute hero badge
- Media queries at 992px (tablet) and 576px (mobile)
- Bootstrap 5 grid, navbar, utilities, buttons, form and table classes
